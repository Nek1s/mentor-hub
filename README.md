# MentorHub

MentorHub — учебный MVP сервиса, в котором ученики ищут наставников, записываются на встречи и сохраняют личные заметки после созвонов.

Проект выполняется последовательно в рамках курса Fullstack. Текущая версия соответствует лабораторной работе №1: в ней подготовлен интерфейс и навигация, а данные пока демонстрационные.

## Возможности первой версии

- просмотр главной страницы с ближайшими встречами и краткой сводкой;
- каталог наставников с поиском и фильтром по направлению;
- экран расписания: выбор даты и свободного времени, создание демонстрационной заявки;
- личные заметки: просмотр и создание заметки в текущей сессии;
- профиль ученика;
- адаптивное меню для небольших экранов.

## Основные пользовательские сценарии

1. Ученик открывает раздел «Наставники», ищет специалиста по навыку и переходит к доступному времени.
2. Ученик на экране «Расписание» выбирает дату и слот, после чего создаёт заявку на встречу.
3. После созвона ученик открывает «Заметки», фиксирует договорённости и может вернуться к ним позже.
4. На главной странице ученик видит ближайший созвон и статус уже созданных заявок.

## Структура проекта

```text
src/
  components/    # общий каркас приложения и переиспользуемые компоненты
  data/          # демонстрационные данные до подключения API
  pages/         # экраны приложения
  App.tsx        # маршруты
  theme.ts       # настройки Material UI
```

## Использованные технологии

- React 19 + TypeScript;
- Vite;
- React Router для переходов между страницами;
- Material UI как библиотека компонентов.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Если PowerShell сообщает, что запуск `npm.ps1` запрещён политикой выполнения скриптов, используйте те же команды с расширением `.cmd`:

```powershell
npm.cmd install
npm.cmd run dev
```

То же правило применяется к остальным командам проекта: `npm.cmd run build`, `npm.cmd run lint` и `npm.cmd run screenshots`. Это позволяет продолжить работу без изменения системной Execution Policy.

После запуска Vite выведет адрес приложения (обычно `http://localhost:5173`). Для проверки production-сборки:

```bash
npm run build
```

Скриншоты реализованных экранов находятся в [docs/screenshots](docs/screenshots):

Чтобы обновить скриншоты после заметных изменений интерфейса, запустите приложение командой `npm run dev`, затем в другом терминале выполните:

```bash
npm run screenshots
```
